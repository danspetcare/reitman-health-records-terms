Reitman Personal Health Tools — WHOOP Connection Privacy Policy

Last updated: October 24, 2026

This WHOOP developer application is a personal, single-user tool operated by Daniel Reitman to retrieve his own WHOOP data into a private research notebook that runs on his own computer. It is not offered to the public and has no other users. This policy explains what the application does with that information.

Information the application accesses

Only the WHOOP data the account holder authorizes on WHOOP's consent screen, limited to the read scopes WHOOP offers developers: profile basics, body measurements, cycles (strain), recovery, sleep and workouts. The application never writes to the WHOOP account and never accesses anyone else's data.

How it is used

Solely so the account holder can view his own recovery, sleep and strain trends alongside his own medical results. The data is not analyzed across people, sold, shared, used for advertising, or used for any other purpose.

Where it is stored

On the author's personal computer only, in a folder readable only by the author's user account. The application sends requests only to WHOOP's own API servers. No information is transmitted to the author's servers, cloud services, analytics providers, advertisers, or any third party.

Retention and deletion

Data stays on the author's computer until he deletes it. Access can be revoked at any time from the WHOOP app or by deleting the stored credentials, after which the application can no longer retrieve anything.

Cookies and tracking

None. This page and the application use no cookies, analytics, or tracking.
